# 虚拟化核心研发工程师（机密计算隔离原型 · Rust）

### 岗位简介

本岗位面向机密计算前沿方向，负责新一代安全监控器的核心研发与原型验证。监控器运行于 CPU 最高特权层，适配目标以国产 CPU 为主（x86-64 海光，ARM64 鲲鹏/飞腾），部署于**无硬件 TEE 能力的通用服务器**，通过将宿主内核降级为 guest 模式运行，实现对机密虚拟机（CVM）的独占资源保护，核心目标是：**切断宿主系统对 GPU/加速卡的全部访问路径，保证明文计算与数据流转不出 CVM 边界（单机场景）**。

**威胁模型与边界（务必理解）**：因无硬件 TEE，本阶段**不提供内存加密**，安全承诺以隔离边界为限——防宿主软件层（含宿主内核与可控制宿主 DMA 的攻击者），不防物理接触/探针级攻击。请勿按 TEE 项目的内存加密预期理解本岗位目标。

**原型阶段范围**：锁定单一国产平台（海光 x86-64 或鲲鹏/飞腾 ARM64 EL2，入职后确定），单台服务器内完成"宿主降级 + CVM 构建 + GPU 独占隔离"全链路跑通。多架构抽象与多平台适配矩阵为后续阶段目标，不作为入职考核项。

### 工作内容

- **宿主降级与接管链路（本岗位核心）**：从启动流程接管 CPU 最高特权层（bootloader/kexec 链式加载、EFI/内存图解析、保留内存区划分），将宿主内核运行于降级 guest 模式（L2），构建嵌套执行世界（nested VMCS / NPT 嵌套 / ARM nested virt），保证宿主功能连续性与性能开销可控

- **Hypervisor 自身防护**：监控器代码段、页表、关键数据结构、拦截策略表的内存自保护，阻断宿主经 DMA 或页表篡改绕过隔离的所有路径（宿主是敌手，不是协作者，所有防护以此为前提设计）

- **CVM 构建与内存视图管理**：二级地址翻译视图（EPT/NPT/Stage-2）页表建设、CVM 内存空映射与归属仲裁、保护域双视图切换、大页映射策略、violation/fault 处理

- **GPU/加速卡隔离专项**：
  - PCI 配置空间拦截与仿真策略（宿主不可见、不可配置 GPU 的 BAR、Command 寄存器、bus mastering 位）
  - GPU 独占归属仲裁与宿主侧拒绝绑定机制（确保宿主驱动永远无法 attach 独占设备）
  - 设备复位（FLR）归属与仲裁、共享页管理
  - 中断重映射（VT-d IR / SMMU 中断注入）保障 GPU 的 MSI-X 只能投递至 CVM 地址空间
  - 原型阶段支持边界的界定与验证（直通模式下 GPU 在 CVM 内可用性的完整 bring-up）

- **敏感资源虚拟化**：MSR/系统寄存器拦截策略表、x86 MSR bitmap 与 VMCB MSRPM 双厂商位图生成、ARM64 系统寄存器 trap 配置、CPUID/ID 寄存器策略引擎（启动期快照、特性位掩码、拓扑枚举受控视图）、CR0/CR4 guest-host mask 与 read shadow、异常注入

- **执行流控制与拦截**：x86 VMCS/VMCB 拦截位图、ARM64 EL2 配置（HCR_EL2 trap 位、VHE）、多架构执行流控制扩展

- **测试与调试**：QEMU 嵌套虚拟化环境 + 目标平台实机环境搭建，GPU 隔离效果的分级验证（宿主枚举不可见 / 宿主驱动绑定失败 / 宿主 DMA 越界触发 violation）

### 任职要求

1. **计算机体系结构**：深入理解 x86-64 长模式分页（四级页表、TLB 语义与刷除时机）、特权级、LAPIC/x2APIC 中断体系、EFER/PAT/MTRR 族 MSR 语义；或深入理解 ARM64 异常级别（EL0–EL3）、Stage-1/Stage-2 地址翻译、VHE、GICv3 中断体系、系统寄存器 trap 机制。两者至少精通其一

2. **硬件虚拟化执行模型**：精通海光 SVM（VMCB save/control 区、vmrun/vmload/vmsave）、AMD SVM 或 Intel VMX（VMCS 三区字段、vmlaunch/vmresume 状态机、instruction error 排障）、ARM EL2 虚拟化（HCR_EL2 trap 控制、Stage-2 fault 处理）至少一种，理解特权层切换时硬件自动保存与恢复的状态集合

3. **嵌套虚拟化与宿主降级经验（核心）**：具备嵌套虚拟化（海光 SVM nested / AMD NPT nested / ARMv8.3+ nested virt）开发调试经验，或 KVM 嵌套路径（L0/L1/L2 世界切换）源码级理解；理解"将运行中的宿主内核降级至非特权模式"的技术路径与坑点

4. **PCIe/GPU 设备层（核心）**：熟悉 PCIe 配置空间、BAR、MSI-X、SR-IOV 机制，有 VFIO 类设备直通、PCIe 设备驱动或 DMA 引擎开发经验；理解 DMA 攻击模型与 IOMMU 攻防（而非仅将 IOMMU 当作功能组件配置）

5. **二级地址翻译**：掌握 EPT/NPT（x86）或 Stage-2（ARM）页表层级与大页映射、violation/fault 限定字段解析，理解 INVEPT/INVLPGA 或 TLBI 指令的适用时机

6. **拦截机制配置**：具备 MSR bitmap、IO bitmap、异常位图、CR guest-host mask 与 read shadow（x86），或 HCR_EL2 trap 位、CPTR_EL2（ARM）中至少两项的实际配置经验

7. **Rust 裸机工程**：熟练进行 no_std 环境开发，掌握内联汇编与 naked function 编写，能够为 unsafe 抽象给出健全性论证

8. **规范精读能力**：能够按章节定位并精确解读海光 CPU 架构规范、AMD APM Vol.2 或 ARM ARM（DDI 0487）的虚拟化相关章节；具备 Intel SDM 阅读能力者可迁移

### 优先条件

- 研读过 HyperEnclave、KVM（arch/x86 或 arch/arm64）、hvpp、SimpleVisor、Jailhouse 等开源 hypervisor 源码

- 有 NVIDIA/国产加速卡直通 bring-up 经验，熟悉 GPU 初始化序列、固件加载、复位行为

- 有 QEMU 嵌套虚拟化调试经验，掌握 GDB remote 与串口日志排障方法

- 具备 VT-d、AMD-Vi 或 SMMUv3 重映射配置实践，含中断重映射（IR）

- 具备国产 CPU 平台（鲲鹏、飞腾、海光）虚拟化适配经验

- 参与过 TEE、SGX、TDX、SEV-SNP、ARM CCA 或机密计算方向项目（理解硬件 TEE 的能力边界即可，本岗位无相关硬件可用）

- 具备外置硬件可信根（FPGA/TPM）协同经验（**后续阶段方向，原型阶段不要求**）

### 非目标（避免预期错位）

- 本阶段不做内存加密、不做远程证明/KMS 链路、不做多机分布式
- 不以代码规模、产品化交付为考核标准，以"GPU 隔离链路在单平台实机跑通 + 隔离效果可验证"为唯一验收目标
