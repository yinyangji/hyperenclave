# 虚拟化核心研发工程师（机密计算隔离原型 · Rust）

### 岗位简介

本岗位负责新一代安全监控器的核心研发与落地（隔离计算方向），部署于无硬件 TEE 的通用服务器，适配目标为 ARM64 鲲鹏。监控器运行于 CPU 最高特权层，通过将宿主内核降级为 guest 模式运行，为受保护隔离虚拟机（下称隔离 VM）提供独占资源保护——核心目标是**切断宿主系统对 GPU/加速卡的全部访问路径，保证计算与数据流转不出隔离 VM 边界**。隔离 VM 由监控器通过软件隔离（二级页表结构性不可达）实现保护，不依赖硬件内存加密。

**威胁模型与边界**：安全承诺限于软件隔离边界——宿主内核与宿主可控 DMA 视为不可信，不防物理层攻击。请勿按内存加密型机密计算项目的预期理解本岗位目标。

### 工作内容

- **宿主降级与接管链路（本岗位核心）**：从启动流程接管 CPU 最高特权层（bootloader/kexec 链式加载、EFI/内存图解析、保留内存区划分），将宿主内核运行于降级 guest 模式（L2），构建嵌套执行世界（ARM nested virt），保证宿主功能连续性与性能开销可控

- **Hypervisor 自身防护**：监控器代码段、页表、关键数据结构、拦截策略表的内存自保护，阻断宿主经 DMA 或页表篡改绕过隔离的所有路径（宿主是敌手，不是协作者，所有防护以此为前提设计）

- **隔离 VM 构建与内存视图管理**：二级地址翻译视图（Stage-2）页表建设、隔离 VM 内存空映射与归属仲裁、保护域双视图切换、大页映射策略、violation/fault 处理

- **GPU/加速卡隔离专项**：
  - PCI 配置空间拦截与仿真策略（宿主不可见、不可配置 GPU 的 BAR、Command 寄存器、bus mastering 位）
  - GPU 独占归属仲裁与宿主侧拒绝绑定机制（确保宿主驱动永远无法 attach 独占设备）
  - 设备复位（FLR）归属与仲裁、共享页管理
  - 中断重映射（SMMU 中断注入）保障 GPU 的 MSI-X 只能投递至隔离 VM 地址空间
  - 平台支持边界的界定与验证（直通模式下 GPU 在隔离 VM 内可用性的完整 bring-up）

- **敏感资源虚拟化**：MSR/系统寄存器拦截策略表、ARM64 系统寄存器 trap 配置、CPUID/ID 寄存器策略引擎（启动期快照、特性位掩码、拓扑枚举受控视图）、CR0/CR4 guest-host mask 与 read shadow、异常注入

- **执行流控制与拦截**：ARM64 EL2 配置（HCR_EL2 trap 位、VHE）

- **测试与调试**：QEMU 嵌套虚拟化环境 + 目标平台实机环境搭建，GPU 隔离效果的分级验证（宿主枚举不可见 / 宿主驱动绑定失败 / 宿主 DMA 越界触发 violation）

### 任职要求

1. **ARM64 虚拟化**：精通 ARM EL2 虚拟化与 ARM64 体系结构（异常级别、Stage-1/Stage-2 地址翻译、VHE、GICv3 中断、HCR_EL2/CPTR_EL2 trap 配置），能独立精读 ARM ARM（DDI 0487）虚拟化章节

2. **嵌套虚拟化与宿主降级经验（核心）**：具备 ARM nested virt 开发调试经验，或 KVM 嵌套路径源码级理解；理解将宿主内核降级至非特权模式的技术路径与坑点

3. **PCIe/GPU 设备层（核心）**：熟悉 PCIe 配置空间、BAR、MSI-X、SR-IOV，有 VFIO 类设备直通或 DMA 引擎开发经验；理解 DMA 攻击模型与 IOMMU 攻防

4. **Rust 裸机工程**：熟练进行 no_std 环境开发，掌握内联汇编与 naked function 编写，能够为 unsafe 抽象给出健全性论证

### 优先条件

- 研读过 HyperEnclave、KVM（arch/x86 或 arch/arm64）、hvpp、SimpleVisor、Jailhouse 等开源 hypervisor 源码

- 具备 Intel VMX 虚拟化实践经验（VMCS 配置、VM-Exit 排障、嵌套虚拟化调试）

- 有 NVIDIA/国产加速卡直通 bring-up 经验，熟悉 GPU 初始化序列、固件加载、复位行为

- 有 QEMU 嵌套虚拟化调试经验，掌握 GDB remote 与串口日志排障方法

- 具备 VT-d、AMD-Vi 或 SMMUv3 重映射配置实践，含中断重映射（IR）

- 具备鲲鹏平台虚拟化适配经验

- 具备外置硬件可信根（FPGA/TPM）协同经验
